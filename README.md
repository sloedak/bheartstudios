# BHEART Studios Website
A website for BHEART Studios LLC, a game studio based in 
 East Lansing, Michigan!

The website will contain a Figma created front title page with clickables
 for each game we make. The Figma design will be uploaded to the GitHub page.
 Each game will have a separate page designed in Figma with executables within
 them. Those designs will come at a later time.
